# 区分个人积分与共同任务积分池

情侣小店永久不涉及金钱，但需要控制积分增发并明确任务奖励的来源。采用个人积分与共同任务池分开的模型：池子由启动赠送、签到和罚分补充；任务发布先足额预留，确认完成后转入个人余额，超额预留退池；商品消费积分退出系统，不向店主或池子回流。伴侣直接赠送保留新增积分，按每日次数及单次比例限制，赠送超额直接消失。

相较于所有奖励直接增发，此方案使任务承诺受可用预算约束，避免完成后才发现无法发奖；代价是需要区分可用、预留及个人余额。后续不得将任务超额退池误记为新增供给，或将负余额罚分在个人补回时再次入池。这些规则已逐项经用户确认，修改会影响历史积分含义，需明确迁移而非当作普通实现简化。

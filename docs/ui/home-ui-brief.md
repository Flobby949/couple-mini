# 首页与导航 UI 图稿说明

状态：用户已选择 A「双人签到台」，尚未进入代码实现。

## 首页的作用

首页是两个人的日常入口：知道今天双方是否签到、共同预算有多少、有什么需要自己处理。不把首页做成购物页，也不把积分规则和所有统计平铺成后台。

## 同一视觉方向下的三个构图

1. 双人签到台（已选择）：成对签到作为主要视觉，随后是共用积分池、个人额度和今日待办，累计双人签到里程碑作收尾。
2. 今日约定：待办和明确截止时间的任务占主导，签到缩为上方短条，适合更多任务和订单时的日常操作。
3. 双人日常卡：以双方头像、签到状态和共享进度组成留白较多的关系卡，再展示少量待办，适合低频、轻量使用。

## 主要页面总览

- 首页：双人签到、共用积分池、个人积分与今日获得额度、待办及里程碑。
- 任务：共同任务与伴侣任务分清，显示待接受、进行中或待确认，伴侣任务显示绝对 deadline。
- 购物：查看伴侣小店，图片必选，显示积分价格、库存、加入购物车和下单；购物车在此页内，结算每次一件一份。
- 我的：个人积分、订单、自己小店管理、伴侣设置、共同规则、按模板的消息通知设置。

## 图稿的行为约束

- 签到基础 10 分直接入池；两人当日都签再入池 10，不显示为个人签到收入。
- 示例中池子总额应等于可用加预留；个人余额与今日已得额度分开。
- 不展示真实金钱、充值、提现、陌生人社交或未要求的纪念日功能。
- 商品示例仅用于设计展示，不意味着给用户自动创建预置商品。
- 所有图稿是视觉预览，按钮和控件不是可操作实现。

## 共用约束

```text
Production UI raster asset for the approved private-couple mini-program. The supplied design board is a STYLE REFERENCE only. Generate ONE isolated reusable asset, not a phone screen or mockup, no collage and no contact sheet. For ILLUSTRATION assets preserve the reference's refined warm 2D illustration language with iris lavender #6752A3, cool pale lavender, muted apricot and sage accents, subtle hand-painted depth; never plastic toy rendering, heavy glossy 3D or neon. NO text, names, letters, numbers, prices, labels, UI controls, notifications, captions, watermarks or status badges baked into the artwork. A clean high-resolution edge with useful margins, nothing clipped. For transparent assets the entire outside must be actual alpha transparency, never a white or checkerboard drawing. PHOTO cover assets instead use natural photorealistic lifestyle photography as explicitly described below. This is a standalone development asset.
```
